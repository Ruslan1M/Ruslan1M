### 🧑‍💻 About me

Unity Developer with **5+ years** of experience building mobile and cross-platform games.
Most recently I developed core gameplay for an unannounced multiplatform third-person shooter at **Plarium**: gameplay systems on ECS, real-time multiplayer netcode, animation synchronization and performance optimization across a wide range of Android and iOS devices.
Before that I shipped gameplay, UI, monetization and platform ports across **20+ projects**.

- 🕹 **Gameplay architecture:** ECS (Entitas), MVVM, state machines, Zenject, ScriptableObjects
- 🌐 **Multiplayer:** custom netcode (ENet), Photon Quantum 3, Photon PUN
- 🎞 **Animation:** custom animation graphs, Unity Timeline, Animator, IK, DOTween
- ⚡ **Performance:** Unity Profiler, Memory Profiler, Frame Debugger, Xcode, Addressables
- 📱 **Platforms:** Android, iOS (native integration), Android TV, PC
- ⚙️ **Async:** UniTask, UniRx, async/await

- 🤖 **AI-assisted development:** Claude Code, Cursor, GitHub Copilot
